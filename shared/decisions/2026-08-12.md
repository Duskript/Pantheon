## Apollo notification fallback for Genre-Lexicon cron
- **Decision:** When `god-notify` failed with `Authentication required`, Apollo appended the completion notification directly to `~/.hermes/notifications.json` using the established chronological append schema.
- **Rationale:** WebUI status reported `hermes-webui — stopped`; `.sessions.json` contained 69 sessions but 0 valid sessions by current epoch-ms comparison, so the authenticated API path was unavailable in cron.
- **Alternatives considered:** Retrying `god-notify` without authentication; attempting to use stale session records. Both were rejected because the endpoint returned 401 and valid session count was zero.
- **Evidence:** Direct fallback verified notifications count `40 → 41`, last title `Genre-Lexicon expanded`, source `god:apollo`, dismissed `False`.
- **Reversibility:** Reversible by deleting the appended notification object if needed; operationally, fixing WebUI/auth would let future runs return to `god-notify`.
