# Pipeline — Growth Operator

**Status:** Planning  
**Type:** high-value operator service  
**Time budget:** 3 hrs/week  
**Time-to-first-dollar:** 1-14 days  

## Offer

Install one revenue workflow for a small business: lead capture, follow-up, content repurposing, or retention loop.

## Target Audience

Small businesses/creators with an offer but weak backend follow-up.

## Weekly Action

Pick one business; audit one leak; send 1 Loom or written mini-audit; offer a $444 setup.

## Validation Event

1 paid $444 setup OR 3 businesses agree the leak exists and want a follow-up.

## Failure Signal

10 mini-audits with no replies; niche/offer too vague.

## Primary Metric

Mini-audits sent, replies, paid setups.

## Minimum Viable Pipeline

1. Define one concrete audience.
2. Publish or create one zero-click proof asset.
3. Capture interest into one tracker: subscriber, reply, booked call, paid trial, source material, or lead.
4. Make one explicit ask only after useful deposits.
5. Review after 7 days; continue only if there is signal.

## Human Approval Gates

- Any outbound message must be reviewed before sending.
- Any claim of results/proof must be source-backed.
- Any platform account/cookie/session use must be explicitly approved.
- Any spending or paid tooling must be approved.
