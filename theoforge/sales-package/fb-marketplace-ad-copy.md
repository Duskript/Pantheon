## How to Post

1. Open Facebook → Marketplace → Sell → Services (or "Item for Sale" if Services isn't available)
2. Category: "Other" or "Business Services"
3. Location: Set to your city/region
4. Price: Optional — Chris says you CAN include it (creates transparency)
5. Boost: Don't boost. The whole point is zero-cost validation. If it works with organic, it works with paid.

## What to Watch For

| Signal | What It Means |
|--------|---------------|
| 5+ messages in first 72 hours | Demand is real — move to close |
| Questions about "how does it work" | They're interested but need clarity → send the Offer Doc |
| "That's too expensive" | Price objection → send Growth tier ($997/mo) as alternative |
| 0-1 messages in a week | Either copy isn't hitting or audience isn't right → try Method B (Groups) |
| DMs asking for your number | **Send the Offer Doc instead.** Don't hop on calls. Let them buy over chat. |
